Why This Matters

Real-world programs rarely perform exactly the same action for every input. Conditional structures allow programs to choose appropriate actions based on data and conditions.

Relational Expressions

A relational expression evaluates a condition as true or false.

grade >= 70
age < 30
number != 250
grade == 100

Logical Conditions

grade >= 70 && grade < 80
opt == 'a' || opt == 'A'
!(length >= 9)

The if Statement

if (expression)
{
    statement;
}

An if statement allows the program to execute a section of code only when a condition is true.

The if-else Statement

if (expression)
{
    statement_TRUE;
}
else
{
    statement_FALSE;
}

The if-else structure provides two possible paths based on the condition.

Nested if

A nested if is an if or if-else statement inside another if statement. It is useful when decisions depend on multiple levels of conditions.

Think About This

When you encounter a decision problem, ask: What condition must be checked, and what should happen when the condition is true or false?

Aralin 1

Daloy ng control

Daloy ng control means the order in which the computer follows instructions.

Sequential execution

Sequential means one after another, like getting ready for school.

#include <iostream>
using namespace std;
int main() {
  cout << "1. Wake up\n";
  cout << "2. Learn C++\n";
  cout << "3. Celebrate!\n";
}

Selection, repetition, invocation

Selection chooses a path. Repetition does something again. Invocation means calling a function.

if (score >= 10) cout << "Level up!";
for (int i = 1; i <= 3; i++) cout << "Jump!";
cheer(); // invoke a function

Aralin 3

Pagsamahin ang mga tanong

Tinutulungan ng logical operators ang program na magtanong ng higit sa isa.

AND: &&

Both sides must be true.

if (homeworkDone && roomClean) {
  cout << "Play time!";
}

OR: || and NOT: !

|| needs at least one true side. ! flips true and false.

if (rainy || tired) cout << "Rest";
if (!locked) cout << "Open";

Try it: safe crossing

Aralin 4

Pumili ng daan gamit ang if

Pinapagawa ng conditional statements ang tamang aksyon depende sa nangyayari.

Five useful shapes

// if
if (x > 0) { ... }

// if-else
if (x > 0) { ... }
else { ... }

// if-ladder
if (grade >= 90) { ... }
else if (grade >= 75) { ... }
else { ... }
// nested if
if (loggedIn) {
  if (isAdmin) { ... }
}

// switch-case
switch (choice) {
 case 1: cout << "Start"; break;
 default: cout << "Unknown";
}
A switch-case is handy for menus. Remember break!

Aralin 6

Invocation: tawagin ang helper

Ang function ay mini-program na may pangalan. Ang invocation ay ang pagtawag dito.

Define, then invoke

void cheer() {
  cout << "You can do it!\n";
}
int main() {
  cheer(); // invoke / call it
  cheer();
}
Functions keep code tidy. Give a job a name, then call that name.
