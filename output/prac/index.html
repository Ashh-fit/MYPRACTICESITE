Lesson 1

Flow of control

Flow of control is the order in which a program follows instructions. Sequential execution runs one line after another. Selection chooses a path, repetition runs code again, and invocation calls a function.

Sequential execution

cout << "First\n";
cout << "Second\n";
cout << "Third\n";

The output follows the same order as the statements.

Task: print steps in order

Write three cout statements that print the steps for making a sandwich.

Lesson 2

Conditions and relational expressions

A relational expression compares values. Its result is either true or false.

Relational operators

grade >= 70
age < 30
number != 250
grade == 100

Remember: == compares values. A single = assigns a value.

Task: check a score

Write an if statement that prints PASS when score is greater than or equal to 70.

Lesson 3

Logical operators

Logical operators combine conditions. AND needs both conditions, OR needs at least one, and NOT reverses a condition.

AND, OR, and NOT

ready && safe
rainy || tired
!locked

Task: safe crossing

Print CROSS only when the light is green and there are no cars. Use &&.

Lesson 4

Conditional statements

Conditional statements let a program choose what to do. Use if, if-else, if-ladders, nested if, and switch-case for different situations.

Common structures

if (condition) { ... }
else { ... }

switch (choice) {
  case 1: ...; break;
  default: ...;
}

Lesson 5

Repetition with loops

Loops repeat instructions. A for loop is useful when you know the number of repetitions. A while loop continues while a condition is true.

Example

for (int i = 1; i <= 5; i++) {
  cout << i << " ";
}

Task: count from 1 to 5

Write a for loop that prints the numbers 1 through 5.

Lesson 6

Invocation and functions

A function is a small named block of code. Invocation means calling the function so it can do its job.

Define and call a function

void greet() {
  cout << "Hello!";
}

int main() {
  greet();
}
